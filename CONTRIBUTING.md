# Как помочь / Contributing

## Новый язык
1. Скопируй `app/src/main/assets/lang/en.json` в `xx.json` (`de.json`, `uk.json`…).
2. Поменяй `_name` (название языка в списке) и переведи **значения**, ключи не трогай.
3. `{0}`, `{1}` — подстановки, оставь их в тексте.
4. `common.error_prefixes` — с чего начинаются сообщения об ошибке в твоём языке, через `|`.
5. Pull request или просто файл в issue.

Проверить без пересборки: положить файл в `Android/data/<пакет>/files/lang/`.

## Код
- Тексты в интерфейсе — только через `tr("ключ")`, не строкой в коде. Новые ключи добавляй в `en.json` и `ru.json`.
- Все файлы проекта — MPL-2.0 (см. `LICENSE`), кроме отмеченных в заголовке.
- Не добавляй в репозиторий файлы игр и чужие ресурсы.
